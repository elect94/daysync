디자인 개선

[파일 형식]
index.html 단일 파일로 만들어줘. CSS는 파일 안의 <style>, JavaScript는 <script>에 모두 포함해줘.
React, JSX, TSX, TypeScript, 프레임워크와 빌드 도구는 사용하지 마. 별도 CSS·JS 파일이나 패키지 설치 없이 브라우저에서 바로 열어 실행할 수 있게 해줘.
수정할 때도 단일 파일 구조를 유지하고, 결과는 생략 없는 index.html 전체 코드로 제공해줘.

기존 기능과 저장된 업무를 유지하면서 화면만 개선해줘.
- 제목과 업무명은 더 읽기 쉽게, 여백은 충분하게.
- 입력 영역과 업무 목록을 명확히 구분.
- 우선순위는 색상뿐 아니라 ‘높음/보통/낮음’ 글자로 표시.
- 완료 상태는 체크와 취소선으로 구분.
- 휴대폰 폭에서 버튼이나 날짜가 잘리지 않게.
디자인 수정 때문에 등록·마감일·완료·브라우저 저장 동작이 바뀌지 않게 해줘.

캘린더 연결 요청

[파일 형식]
index.html 단일 파일로 만들어줘. CSS는 파일 안의 <style>, JavaScript는 <script>에 모두 포함해줘.
React, JSX, TSX, TypeScript, 프레임워크와 빌드 도구는 사용하지 마. 별도 CSS·JS 파일이나 패키지 설치 없이 브라우저에서 바로 열어 실행할 수 있게 해줘.
수정할 때도 단일 파일 구조를 유지하고, 결과는 생략 없는 index.html 전체 코드로 제공해줘.

기존 업무용 플래너에 ‘Google 캘린더에 추가’ 기능을 넣어줘.
기존 업무, 완료 상태와 localStorage 저장은 유지해.

- 마감일이 있는 업무마다 ‘Google 캘린더에 추가’ 버튼 표시.
- 버튼은 https://calendar.google.com/calendar/r/eventedit 를 사용한 미리 채워진 일정 작성 링크를 새 탭으로 열어줘.
- action=TEMPLATE, text에는 업무명, details에는 우선순위와 ‘업무 플래너에서 추가한 일정’ 설명을 넣어줘.
- 마감일을 종일 일정으로 전달. dates는 YYYYMMDD/YYYYMMDD 형식이며, 종료일은 마감일 다음 날(배타적 종료일).
- 월말과 연말도 올바르게 다음 날로 계산. 한글·공백·& 등 특수문자는 URLSearchParams 등으로 인코딩.
- 마감일이 없으면 비활성화하고 ‘마감일을 먼저 설정해 주세요’ 안내.
- 클릭한 링크는 새 탭으로 열고 rel=noopener noreferrer 적용.
- 제목과 우선순위가 Google로 전달됨을 버튼 근처에 안내.
- ‘Google 캘린더에서 확인 후 저장하세요. 이후 변경은 자동 동기화되지 않습니다’ 표시.
- 링크를 열었다고 ‘등록 완료’라 표시하지 마. 중복 저장 여부는 자동으로 판단할 수 없음을 안내.
- 별도 API 키, OAuth 로그인 구현, 서버 연결은 추가하지 마.
